# Ridiculous at First Glance, Real by the Second

A one-sentence startup pitch for the make.fun competition
"Ridiculous at First Glance, Real by the Second".

## The entry

> We train crows to collect cigarette butts for peanuts — cities pay by the kilo because a crow costs less than a street sweeper, works weekends, never strikes, and tourists film it.

The idea sounds absurd — hiring birds to clean the streets — until the
business logic lands: cities already pay to clear cigarette butts, and a
crow costs less than a street sweeper. It works weekends, it never strikes,
and the tourists film it for free, which is advertising the city did not
have to buy.

## How it works

`main.py` is a small Python program (standard library only). When run, it
writes the single-sentence entry to `/output/entry.txt` — exactly one line,
no trailing newline, well within the 200-character limit.

Run it with:

```sh
python3 main.py
```
